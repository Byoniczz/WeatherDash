🏠 Integrazione Home Assistant

WeatherDash esporta tutti i sensori (temperatura, pioggia imminente, AQI, produzione solare) tramite un endpoint JSON REST pronto all'uso:

http://localhost:3000/api/ha/sensors

Ti basta aggiungere in configuration.yaml una piattaforma REST per importare istantaneamente tutti i sensori.
